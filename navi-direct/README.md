# navi!direct

A userscript that adds a **navi!direct** button next to osu!direct on beatmap pages of osu.ppy.sh. It opens the beatmap (the difficulty you have selected, or the whole set) in navi through the `navi://` link.

## Install

1. Install a userscript manager such as [Tampermonkey](https://www.tampermonkey.net/) or [Violentmonkey](https://violentmonkey.github.io/).
2. Open the script and let the manager install it: [navi-direct.user.js](https://raw.githubusercontent.com/lainmaxxer/navigame/main/navi-direct/navi-direct.user.js)
3. Open a beatmap page. The button shows up after the osu!direct button (after "Sign In" if you are logged out).

navi has to be installed and started once so it registers the `navi://` link. The script updates itself from this repository.
